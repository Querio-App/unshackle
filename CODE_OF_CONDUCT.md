# Code of conduct

Be kind. Assume good intent. Disagree about code, not people.

Not okay here: harassment, insults, personal attacks, sexual language or
imagery, publishing someone's private information, or anything else you
wouldn't do in front of a colleague.

This applies in issues, pull requests, discussions and anywhere you
represent the project.

Maintainers can edit or remove comments and contributions, and warn or ban
anyone who breaks these rules.
