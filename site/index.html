Get your BI out of the BI tool.

unshackle is an open-source command-line tool. It reads the metrics, queries, dashboards and permissions from your BI tool and writes them as open formats in a Git repository. What it can't translate faithfully, it marks as a TODO instead of guessing.

GitHub PyPI Contribute

Install

$ pip install unshackle
$ unshackle tools
$ unshackle migrate tableau

No API access? Download the files from the tool and run unshackle import.

Reads

Looker · Tableau · Power BI · Qlik Sense · Amazon QuickSight · Metabase · Lightdash · Apache Superset · Redash · Omni · Hex · Sigma · ThoughtSpot

Writes

  • Apache Ossie semantic models, and MetricFlow in dbt projects
  • Jupyter notebooks with SQL tiles and Altair (Vega-Lite) charts
  • SQL queries, table and column descriptions
  • Cedar policies and SQL row filters

Check the numbers

unshackle verify runs the migrated SQL against your warehouse and compares it with the results from the old tool.

The name

In January 1915, Ernest Shackleton's ship Endurance froze into the pack ice of the Weddell Sea. It drifted with the ice for most of a year before it was crushed and sank. All 28 men aboard still made it home, after a lifeboat crossing to South Georgia that is still hard to believe. The wreck was found in 2022, 3,000 metres down. Data stuck in a BI tool is a smaller problem, but we liked the name.

If you've never read the story, start with Alfred Lansing's Endurance: Shackleton's Incredible Voyage (1959). For Frank Hurley's photographs from the expedition, see The Endurance Photographs, published with the Royal Geographical Society.
